# Grade 5 Mathematics

## Topic 1: Place Value of Whole Numbers

### Learning Objectives

- Identify the place value of digits in numbers up to millions
- Read and write numbers in words and figures
- Understand the value of each digit according to its position

### Key Concepts
Every digit in a number has a place value depending on its position.

In the number 4,582,317:

- 7 is in the ones place (value = 7)
- 1 is in the tens place (value = 10)
- 3 is in the hundreds place (value = 300)
- 2 is in the thousands place (value = 2,000)
- 8 is in the ten thousands place (value = 80,000)
- 5 is in the hundred thousands place (value = 500,000)
- 4 is in the millions place (value = 4,000,000)

### Place Value Chart (from right to left)
Ones → Tens → Hundreds → Thousands → Ten Thousands → Hundred Thousands → Millions

### Reading Numbers
4,582,317 is read as “four million, five hundred eighty-two thousand, three hundred seventeen”.

### Important Tip
Always start from the right when identifying place values. Commas help group digits in threes.

### Summary
Place value tells us the real value of a digit based on its position. Knowing place value helps with reading, writing, comparing, and calculating with large numbers.

### Common Mistake
Confusing the place (position) with the actual value of the digit.

## Topic 2: Ordering and Comparing Whole Numbers

### Learning Objectives

- Compare whole numbers using greater than (>), less than (<) and equal to (=)
- Arrange numbers in ascending and descending order
- Use place value to compare numbers

### Key Concepts
To compare two numbers, start from the highest place value (left side).

**Example:** Compare 45,678 and 45,768

- Both have 4 ten thousands and 5 thousands
- Next digit: 6 hundreds vs 7 hundreds → 45,678 < 45,768

### Symbols

- means greater than
- < means less than
- = means equal to

**Ascending order** = from smallest to largest
**Descending order** = from largest to smallest

**Example**
*Numbers: 3,245 · 3,425 · 3,245 · 3,542
*Ascending: 3,245 · 3,245 · 3,425 · 3,542
*Descending: 3,542 · 3,425 · 3,245 · 3,245

### Summary
Always compare digit by digit from the left. The first different digit decides which number is larger.

### Common Mistake
Looking only at the number of digits or the last digits instead of starting from the highest place value.
